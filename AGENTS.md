# opencode-plugin-yandex-ai-studio — AGENTS.md

Инструкции и знания о платформе OpenCode (v2.0.x), без которых плагин «не работает». Актуально и для контрибьюторов, и для AI-агентов, работающих с репозиторием.

## Важные особенности OpenCode (v2.0.x)

1. **Корневой entry обязателен.** Загрузчик конфигурированных плагинов ищет части по именам файлов в корне каталога (`index.ts` → серверная, `tui.tsx`, `rpc.ts`); каталог без них **молча пропускается** — ни ошибки, ни warning в логах. В корне репо лежат тонкие реэкспорты, не удаляйте их.
2. **`enabled_providers` скрывает провайдера.** Если ключ задан в конфиге пользователя, провайдер не из списка не появится в пикерах моделей, хотя зарегистрируется нормально. Не «лечите» это в коде — это ожидаемое поведение конфига.
3. **Не смешивать ключи `plugin` (V1) и `plugins` (V2) в одном конфиге.** Миграция legacy-ключа может перезатирать V2-массив.
4. **Env-переменные `YC_API_KEY`/`YC_TOKEN`/`YC_IAM_TOKEN`/`YC_SERVICE_ACCOUNT_KEY*` подменяют авторизацию `yc`** (CLI даёт им приоритет над профилем). Плагин вырезает их при spawn (`cleanYcEnv` в `src/token.ts`) — иначе `iam create-token` выпускает токен сервисного аккаунта от чужого API-key → 403 от API. Любой новый spawn `yc` обязан делать так же.

## Отладка-квиз (выяснено живьём)

- **Гонки холодного старта location.** Первый запрос из TUI (RPC-метод, список команд) может прийти раньше, чем плагин загрузится → HTTP 400 / команда отсутствует в списке. Само проходит после загрузки; UI-часть должна быть к этому готова (не делать выводов по одному фейлу, ретраить).
- **TUI-часть подхватывает изменения только перезапуском TUI-приложения** (Bun-трансформация кэшируется на старте процесса); серверная часть — хот-релоадом по watcher'у.
- **Слоты:** `home.footer.status` — только футер домашнего экрана; для индикатора в сессии нужен отдельный claim на `prompt.footer.status`.
- **`session.synthetic` = сообщение с `delivery: steer`**, т.е. промпт для модели. Для чисто-UI отчётов используйте RPC-событие + toast (см. `usage.report` в `src/rpc.ts`), не synthetic.
- **`opencode api` CLI резолвит локацию не из cwd** — для проверки живого состояния используйте `opencode api get /api/plugin`, `/api/command`, `/api/model`.

## Правила кода

- Не логировать IAM-токен целиком — только `token.slice(0, 6)…` (`redact()` в `src/token.ts`).
- Все внешние ошибки с HTTP-статусом — `ApiHttpError` (`src/models.ts`), ветвления по статусу, не по тексту сообщения.
- Порог предупреждения квоты — единая константа `QUOTA_WARN_PERCENT` (`src/rpc.ts`).
- Проверка типов: `npx tsc --noEmit` из корня репо.
